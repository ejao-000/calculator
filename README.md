Calculator App
A modern calculator built using HTML, CSS, and JavaScript. The application performs basic arithmetic operations and includes five customizable themes: Dark, Light, Blue, Green, and Purple.

Features
 - Addition, subtraction, multiplication, and division
 - Percentage calculations
 - Decimal number support
 - Clear screen functionality (AC)
 - Delete last character (⌫)
 - Responsive design
 - Five switchable themes
 - User-friendly interface
 -

 - HTML5
 - CSS
 - JavaScript

Installation
 1. Clone the repository:
  git clone https://github.com/ejao-000/calculator.git

 2. Navigate to the project folder:
  cd calculator

 4. Open index.html in your browser.
Usage
 - Click the number buttons to enter values.
 - Use the operation buttons (+, −, ×, ÷) to perform calculations.
 - Press = to display the result.
 - Press AC to clear the screen.
 - Press ⌫ to remove the last entered character.
 - Click the Theme button to cycle through the available themes.
